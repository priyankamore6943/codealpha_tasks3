# Basic Chatbot Using Python 🤖

## 📌 About the Project
Basic Chatbot is a simple, rule-based chatbot developed using Python. It interacts with users through text messages and responds to basic greetings, questions, and commands.

## ✨ Features
- Responds to greetings like Hello, Hi, and Hey
- Answers basic questions
- Displays the current date and time
- Provides simple help instructions
- Allows users to exit the conversation
- Easy-to-use command-line interface

## 🛠️ Technologies Used
- Python
- Functions
- Conditional Statements
- Loops
- Date and Time Module

## ⚙️ Installation and Setup

**Step 1:** Install Python on your computer.

**Step 2:** Clone this repository:

```bash
git clone https://github.com/YOUR-USERNAME/BasicChatbot.git
```

**Step 3:** Open the project folder:

```bash
cd BasicChatbot
```

**Step 4:** Run the program:

```bash
python main.py
```

Replace `YOUR-USERNAME` with your GitHub username.

## 💬 Example Output

```text
Bot: Hello! I am your chatbot.
```

## 🎯 Learning Outcomes
This project helps beginners understand Python programming concepts such as user input, functions, loops, conditional statements, and basic text processing.

## ⚠️ Limitations
This is a rule-based chatbot that responds to predefined keywords. It does not use machine learning or advanced artificial intelligence.
